# LLM-Assisted Adaptation on the Randomized Benchmark

The LLM-assisted runner now accepts both:
- the original `ai-act-benchmark-*.yaml` dataset
- the randomized `ai-act-random-stress-*.yaml` dataset

This enables a valid LLM/no-LLM comparison on the same 100 randomized systems.

Use a separate results directory to preserve the earlier 21-system LLM-assisted results.
